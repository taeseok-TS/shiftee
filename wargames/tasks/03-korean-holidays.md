# 미션 브리프 03 — 한국 공휴일 연동

## 배경
- 휴가 일수 계산이 **주말만** 제외한다 (`api/leave/route.ts:93` — `getDay !== 0 && !== 6`).
  공휴일이 낀 연차 신청은 공휴일까지 차감된다.
- 출퇴근 상태 판정(지각 9시/조퇴 18시)이 공휴일을 모른다.
- `ScheduleType`에 `HOLIDAY`가 있지만 수동 입력용이다.

## 원하는 것
1. 한국 공휴일(대체공휴일 포함) 데이터 소스 확보 — ledger의 `(공휴일_데이터_소스)` 참조.
   API 키가 없으면 정적 테이블 + 관리자 편집 UI 경로로.
2. 휴가 일수 계산에서 공휴일 제외.
3. 캘린더/일정 화면에 공휴일 표시.
4. (정책 확정 시) 공휴일 출근 기록의 지각/조퇴 판정 제외.

## 성공 조건 (미션 특화)
- 공휴일이 낀 기간의 연차 신청 시 차감 일수가 공휴일을 제외한 값과 일치.
- 설/추석 등 음력 기반 공휴일과 대체공휴일이 올바른 날짜로 존재.
