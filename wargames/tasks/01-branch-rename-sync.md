# 미션 브리프 01 — 지점명 실제화 + 이름 변경 동기화

## 배경
- 지점 15개가 "A지점"~"O지점" 플레이스홀더 이름으로 등록되어 있고, 실제 지점명으로 교체해야 한다.
- `User.branch`는 FK가 아니라 `Branch.name`과 **문자열로** 매핑된다.
- 현재 `PATCH /api/branches/[id]`는 지점명을 바꿔도 소속 직원의 `User.branch`를 갱신하지 않는다
  → 이름을 바꾸는 순간 직원-지점 연결이 전부 끊어진다.

## 원하는 것
1. 지점명 변경 시 소속 직원의 `User.branch`가 **원자적으로(트랜잭션)** 함께 갱신되는 동기화 로직.
2. 그 로직 위에서 A~O → 실제 지점명 일괄 교체 (매핑표는 ledger의 `(실제_지점명_매핑)` 입력 후).
3. 이름 변경이 로그인 중인 사용자(JWT 세션의 `branch` 클레임)에게 미치는 영향의 완화책.

## 성공 조건 (미션 특화)
- 이름 변경 후: 해당 지점 직원의 지오펜스 출퇴근, MANAGER의 지점 필터, 직원 목록 지점 카드가 모두 정상.
- 감사 로그(`logAudit`)에 변경 전/후 지점명과 영향받은 직원 수 기록.
