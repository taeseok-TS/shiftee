# 미션 브리프 02 — 연차 연도 전환 (신년도 LeaveBalance 생성/이월)

## 배경
- `LeaveBalance`는 `userId @unique` — **유저당 딱 1행**이고 `year`는 그냥 컬럼이다.
  연도가 바뀌어도 아무 일도 일어나지 않으며, 전년도 이력을 남길 방법이 없다.
- `POST /api/leave/balance/recalc`(근속 기반 재계산)와 `PATCH /api/leave/balance`(수동 조정)가
  이미 존재하고 같은 행을 덮어쓴다.

## 원하는 것
1. 연도 전환 실행 시: 전년도 잔여를 이력으로 보존하고, 신년도 total(근속 기반 `annualLeaveDays`)로
   초기화된 잔여를 만든다. 이월 여부는 ledger의 `(이월_정책)`을 따른다.
2. 실행 방식은 관리자 수동 버튼(연차 관리 화면) — 멱등해야 하며 같은 연도에 두 번 눌러도 안전할 것.
3. 기존 recalc/수동조정/휴가신청 차감 로직과 충돌하지 않을 것.

## 성공 조건 (미션 특화)
- 전환 후 휴가 신청 → 차감 → 승인/반려 복원 흐름이 신년도 행에서 정상 동작.
- 전년도 데이터가 조회 가능한 형태로 남아 있음.
- 감사 로그에 전환 실행 기록.
