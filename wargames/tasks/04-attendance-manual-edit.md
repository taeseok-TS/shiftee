# 미션 브리프 04 — 출퇴근 기록 수동 수정 (관리자)

## 배경
- 현재는 `PATCH /api/attendance/[id]/auto-fill`(출근+9시간/퇴근-9시간 휴리스틱)만 존재.
- 관리자가 임의의 시각으로 출퇴근을 고치거나, 기록이 없는 날짜에 기록을 만들 수 없다.
- 상태(LATE/EARLY_LEAVE/NORMAL) 재계산 로직이 auto-fill 라우트 안에 인라인으로 박혀 있어
  새 수정 API를 만들면 로직이 중복될 위험.

## 원하는 것
1. 관리자가 특정 직원·날짜의 clockIn/clockOut을 임의 시각으로 수정하는 API + UI(관리자 출퇴근 화면).
2. 기록이 없는 날짜에 새 기록 생성 (ledger `(기록_생성_허용)` 기본값: 허용).
3. 상태 재계산 로직을 공용 함수로 추출해 auto-fill과 공유 (중복 금지).
4. 모든 수정에 감사 로그 (변경 전→후 시각).

## 성공 조건 (미션 특화)
- 수정 결과가 출퇴근 통계(`/api/attendance/stats`)와 목록에 즉시 반영.
- clockOut < clockIn 같은 비정상 입력이 400으로 거부됨.
- 기존 auto-fill 동작이 회귀 없이 유지.
