# 원장 (Ledger) — 차단 요소 / 사용자 입력 필요 변수

워게임 정찰(recon)로도 해소할 수 없는 변수들. 실행 전에 사용자가 채워야 하며,
비어 있는 변수에 의존하는 수(move)는 해당 워게임의 중단 조건을 따른다.

## 미션 01 — 지점명 실제화

| 변수 | 상태 | 설명 |
|------|------|------|
| `(실제_지점명_매핑)` | 🔴 미입력 | A지점~O지점 → 실제 지점명 15개 매핑표. 이것 없이는 이름 변경 실행 불가 (동기화 인프라 구축까지는 가능) |
| `(지점명_중복_정책)` | 🔴 미입력 | 실제 지점명이 서로 겹치거나 기존 이름과 충돌할 때 처리 방침 |

## 미션 02 — 연차 연도 전환

| 변수 | 상태 | 설명 |
|------|------|------|
| `(이월_정책)` | 🔴 미입력 | 잔여 연차 이월 여부: 전액 이월 / 상한 N일 이월 / 소멸(근로기준법 기본). 미입력 시 워게임은 "소멸 + 신년도 재부여"를 기본값으로 가정 |
| `(전환_시점)` | 🟡 기본값 있음 | 연도 전환 실행 방식. 기본값: 관리자 수동 버튼 (Windows 상시 서버가 아니므로 cron 불가 가정) |

## 미션 03 — 한국 공휴일 연동

| 변수 | 상태 | 설명 |
|------|------|------|
| `(공휴일_데이터_소스)` | 🟡 기본값 있음 | 공공데이터포털 특일정보 API 사용 시 서비스 키 필요. 키 미입력 시 워게임은 정적 테이블(2026~2027 하드코딩 + 관리자 편집 UI) 경로로 분기 |
| `(공공데이터포털_서비스키)` | 🔴 미입력 | API 경로 선택 시에만 필요 |
| `(공휴일_지각판정_정책)` | 🟡 기본값 있음 | 공휴일에 출근한 직원의 지각/조퇴 판정 여부. 기본값: 공휴일에는 LATE/EARLY_LEAVE 판정 안 함 |

## 미션 04 — 출퇴근 수동 수정

| 변수 | 상태 | 설명 |
|------|------|------|
| `(수정_권한_범위)` | 🟡 기본값 있음 | 기본값: ADMIN 전용 (기존 auto-fill과 동일). MANAGER 허용 여부는 사용자 결정 |
| `(기록_생성_허용)` | 🟡 기본값 있음 | 기록이 아예 없는 날짜에 관리자가 새 출퇴근 기록을 만들 수 있는지. 기본값: 허용 |
